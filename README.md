# FeedbackFlow

**AI-powered customer feedback platform for small businesses.**

FeedbackFlow helps SMBs collect, analyze, and act on customer feedback using AI-powered insights — turning raw responses into clear, actionable growth opportunities.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

## Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Landing Page Sections

1. **Hero** — Value proposition + dual CTA
2. **Features** — 6 key capabilities with icons
3. **Pricing** — 3-tier plan comparison (Starter $0, Growth $49, Pro $129)
4. **Contact** — Demo request form
5. **Footer** — Navigation + copyright
